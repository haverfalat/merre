# BKK transport pictograms

Original source: https://go.bkk.hu/ride-gui/3.18.0-251972-2069795-86d980c0/css/img/arculat-100px.png

The six 100×100 cells follow the original `css/style.css` `.agazat-logo` coordinates (20px CSS grid scaled by five). Retrieved 2026-10-28. Original artwork and branding belong to their respective owners; this directory does not assert a new license or official affiliation.

`*-symbol.png` contains only the foreground pictogram (white or dark in the original artwork) as a transparent mask, tightly fitted into an 80×80 canvas. UI icons tint these masks with their existing theme color; map stop icons use the same masks in light/dark variants. The original circle badges remain available for BKK headers.
