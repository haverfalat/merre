MNR2007.ttf is the bundled MÁV railway symbol font. It supplies route labels and onboard amenity symbols. Generated map glyph PNGs come from this same font; regenerate them with npm run assets:glyphs.

Geist and Geist Mono are bundled locally through @expo-google-fonts/geist and @expo-google-fonts/geist-mono. Only the four imported font weights are included; the app does not fetch fonts at runtime.
