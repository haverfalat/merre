Improves selection of overlapping map stops with a compact chooser showing route numbers and directions instead of internal stop IDs.

Opening a stop from a vehicle shows departures from that vehicle's expected arrival time when available. The full timetable action resets departures to now, dismisses itself, and preserves a back action to the original vehicle.

Separates explicit depot and other service notices from vehicle destinations. Vehicle alerts expand directly beneath their disclosure. Exact train-number matches appear before matching routes in search; recent vehicle observations add priority.

Includes a local release command for Git push, GitHub mobile builds, draft releases and compatible production OTA updates.

Validation: lint and TypeScript checks. Device interaction and visual review remain manual.
